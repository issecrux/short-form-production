# Sound Framework — numbers from the PR/AE Masterclass distillation (STUDY_NOTES Stage D)

All levels are relative to voice unless stated otherwise. This is the
course's talking-head framework, distilled from the Premiere Pro and After
Effects masterclasses.

## Levels

| Element | Level | Notes |
|---|---|---|
| Voice | −6 to −12 dB | ideal ±−9 dB |
| Music (under narration) | −20 to −24 dB | −17 dB is only for narration-free demos (AE-40) — not a replacement framework |
| Texture | −5 dB | the layer under the whoosh |
| Heavy whoosh (final) | −5 dB | |
| General whoosh | −10 dB | |
| Small whoosh | −15 dB | |
| UI click | −10 dB | replaces the whoosh for pop-ups |
| Riser | −10 dB | **exactly ONE per video**, at the intro bridge |
| General SFX | −10 to −15 dB | |
| Background/ambience | −15 to −20 dB | the quietest element |

## Doctrine

- **Movement = whoosh.** Every meaningful visual movement can take one
  whoosh; there are 3 whoosh kinds (heavy, general, small) — pick by the
  scale of the movement.
- Sound layer order: **whoosh → texture → riser/hit**. Never stack risers;
  one well-placed riser beats three random ones.
- Music: build a library per mood, A/B-test with a loop before deciding.
- Export audio: AAC 48 kHz; video bitrate 20.
