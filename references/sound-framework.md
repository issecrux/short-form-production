# Kerangka Sound — angka dari distilasi PR/AE Masterclass (STUDY_NOTES Tahap D)

Semua angka relatif terhadap voice, kecuali dinyatakan lain. Ini kerangka
Joseph untuk talking-head; standar Rima di bawahnya adalah amendemen yang
mengikat untuk produksi kita.

## Level

| Elemen | Level | Catatan |
|---|---|---|
| Voice | −6 s.d. −12 dB | ideal ±−9 dB |
| Music (di bawah narasi) | −20 s.d. −24 dB | −17 dB hanya untuk demo tanpa narasi (AE-40) — bukan pengganti kerangka |
| Texture | −5 dB | lapisan di bawah whoosh |
| Whoosh berat (final) | −5 dB | |
| Whoosh umum | −10 dB | |
| Whoosh kecil | −15 dB | |
| UI click | −10 dB | menggantikan whoosh untuk pop-up |
| Riser | −10 dB | **tepat SATU per video**, di jembatan intro |
| SFX umum | −10 s.d. −15 dB | |
| Background/ambience | −15 s.d. −20 dB | elemen paling pelan |

## Doktrin

- **Movement = whoosh.** Setiap gerakan visual yang berarti dapat satu
  whoosh; ada 3 jenis whoosh (berat, umum, kecil) — pilih menurut skala
  gerakannya.
- Urutan lapis bunyi: **whoosh → texture → riser/hit**. Jangan menumpuk
  riser; satu riser yang ditempatkan benar mengalahkan tiga riser acak.
- Musik: bangun library per mood, uji A/B dengan loop sebelum memutuskan.
- Export audio: AAC 48 kHz; video bitrate 20.

## Amendemen Rima (mengikat, dari produksi Pick #1–3)

- **Sound design SELALU full layer** — bukan versi minimal. Keyword SFX
  dicari dari katalog DULU (sintesis hanya bila katalog tidak punya),
  ditempatkan di **onset kata** yang dirujuk, bukan di awal chunk caption.
- SFX harus **terasa**: kehadiran dan kekayaan bunyi di atas kesopanan
  level. Pengulangan SFX yang sama harus **bervariasi pitch/volume**
  (tangga nada) — SFX identik berulang terdengar seperti template.
- BGM untuk campaign: lagu trending versi **instrumental**, dibakar ke
  dalam klip sebagai bed di bawah dialog.
- Loudness final diukur, bukan ditebak: target ±−18 LUFS terintegrasi
  dengan tahap volume + alimiter (limiter memakan ±2–3 dB gain terapan).
